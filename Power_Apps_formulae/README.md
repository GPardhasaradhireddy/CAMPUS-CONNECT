# Campus Connect - Power Apps Formulae

Welcome to the **Power Apps Formulae** module of the **Campus Connect** project.

## Overview

This directory is designated for storing the custom Power Fx formulas, logic snippets, and algorithmic calculations used within the Campus Connect Power Apps frontend. 

*Currently, this directory is empty as the formulas are embedded directly within the Power Apps `.msapp` package. Future extractions or complex logic documentation will be added here.*
