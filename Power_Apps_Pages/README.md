# Campus Connect - Power Apps UI

Welcome to the **Power Apps Pages** module of the **Campus Connect** project. This directory contains the visual representations and screenshots of the front-end user interface built using Microsoft Power Apps.

## Overview

The Power Apps interface acts as the primary gateway for students and administrators to interact with the Campus Connect platform. It is designed to be intuitive, responsive, and data-rich, providing a seamless user experience across devices. The UI leverages modern design principles to ensure that all campus services are just a click away.

## Interface Highlights

The screenshots provided in this folder demonstrate key pages of the application:

### 1. Main Dashboard
The central hub for students upon logging in. 
- **Personalized Greeting:** Displays the student's roll number.
- **KPI Cards:** At-a-glance view of critical metrics such as Current CGPA, Attendance Percentage, Pending Fees, and active Backlogs.
- **Sidebar Navigation:** Easy access to all modules including Profile, Event Registrations, Notices, Placements, Leave Applications, Complaints, and more.
- **Quick Access:** Prominent buttons for frequently used services.

### 2. AI Chatbot Integration (Groot AI)
An integrated AI assistant available directly on the dashboard.
- **Groot AI:** A personalized, persistent chatbot window that can answer queries regarding attendance, CGPA, complaints, and more.
- **Quick Prompts:** Pre-defined action buttons to streamline user interactions.

### 3. My Profile Page
A comprehensive view of the student's academic and personal identity.
- **Profile Header:** Contains the user's photo, roll number, course details (e.g., B.Tech, ECE, Year 3), and summary badges (CGPA, Attendance, Backlogs).
- **Personal Information:** Detailed contact and demographic data including Email, Mobile, Entrance Type, DOB, and Guardian details.
- **Academic Details:** In-depth academic records including Programme, Current Semester, SGPA, Credits Earned, and overall CGPA.

## Technology Stack
- **Frontend Framework:** Microsoft Power Apps
- **Styling:** Custom glassmorphism UI and modern web design principles
- **Integration:** Directly connected to SharePoint data and Power Automate flows
